# Design Patterns Demo

An educational .NET solution demonstrating design patterns in real-world scenarios.

## Structure

Each design pattern is organized in its own folder:

- **Strategy/** - Strategy pattern demonstration

## Getting Started

This is a .NET 10 Console Application. To run:

```bash
dotnet build
dotnet run
```
